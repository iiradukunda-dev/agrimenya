# Product demonstration

Place the final screen-recorded product walkthrough in this folder as
`demo.webm` or `demo.mp4`. Keep it to three minutes or less and show the
working interface and representative user interactions, such as exploring
zones, reviewing crop evidence, and opening a planning or decision workflow.

Record from a computer rather than filming a monitor with a phone, unless the
project being demonstrated is itself a mobile app. The existing
`frontend/assets/landing video.mp4` is a website asset and is not the project
walkthrough.
