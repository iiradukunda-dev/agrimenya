# Eligibility documents

This folder is intentionally empty. Student cards and other eligibility
documents contain personal information and must not be committed to the
project's public GitHub repository.

Submit only the minimum official evidence required, through the organizers'
approved private channel. Before sharing any document, confirm that both
members have agreed and that the submission method is authorized. If the
organizers explicitly require repository submission, use only a restricted
repository approved for handling these records.

Eligibility documents have not been added here.
